# 舆情分析维度详解

## 数据结构

输入 `xhs_data.json` 每条记录：

```json
{
  "title": "笔记标题",
  "author": "作者昵称",
  "content": "笔记正文",
  "url": "笔记链接",
  "likes": 128,
  "collects": 45,
  "comment_count": 23,
  "scraped_at": "2026-04-15",
  "comments": [
    {"user": "用户A", "content": "评论内容", "likes": 5}
  ]
}
```

## 1. 情感分析

按正面 / 负面 / 中性三分类，分别对笔记正文和评论打标。

**判定规则**：
- 正面：推荐、好评、种草、回购、惊艳
- 负面：踩雷、难用、退款、失望、差评
- 中性：纯描述、提问、无明显倾向

**输出**：占比饼图数据 + 每类 Top 3 典型案例（摘要 + 链接）

## 2. 热词提取

对所有笔记正文 + 评论做中文分词，过滤停用词后统计词频。

**输出**：Top 20 高频词 + 词频，按频次降序排列

## 3. KOL 识别

按互动量（点赞 + 收藏 + 评论数）排名作者。

**输出**：
| 排名 | 作者 | 笔记数 | 总互动量 | 代表作 |
|------|------|--------|---------|--------|

## 4. 话题聚类

按关键词相似度将笔记分组，每组提炼主题标签。

**常见聚类维度**：
- 产品体验（使用感受、效果评价）
- 价格讨论（性价比、优惠活动）
- 对比评测（vs 竞品）
- 教程攻略（使用方法、搭配建议）
- 售后服务（客服、退换货）

**输出**：每个话题的笔记数、典型笔记、情感倾向

## 5. 竞品对比

统计笔记和评论中竞品品牌被提及的频次。

**输出**：
| 品牌 | 提及次数 | 正面占比 | 负面占比 | 常见关联词 |
|------|---------|---------|---------|-----------|

需要用户提供竞品品牌列表，或从笔记中自动识别同品类高频品牌。

## 6. 时间趋势

按日期聚合发布量和情感变化。

**输出**：
- 每日/每周发布量折线
- 情感占比随时间变化
- 标注异常峰值及可能原因（如营销活动、负面事件）
